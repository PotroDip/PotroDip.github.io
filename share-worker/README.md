# শেয়ার-প্রিভিউ ওয়ার্কার

ফেসবুক, হোয়াটসঅ্যাপ, টেলিগ্রাম, X, লিংকডইন, ডিসকর্ড — যেখানেই লেখার লিংক শেয়ার হবে, সেখানে **ওই লেখার টাইটেল, সারাংশ ও কভার-ছবি** দেখাবে (সাইটের লোগো নয়)।

## কেন এটা লাগে
`potrodip.github.io` স্থির (static) সাইট। লেখার পেজ ব্রাউজারে JS দিয়ে Supabase থেকে ডেটা আনে, কিন্তু ফেসবুক-জাতীয় ক্রলার JS চালায় না — তারা শুধু `article.html`-এর ভেতরের স্থির ট্যাগ দেখে। এই ওয়ার্কার শেয়ার-লিংকে ক্রলারকে সঠিক ট্যাগ দেয়, আর পাঠককে সঙ্গে সঙ্গে আসল লেখায় পাঠিয়ে দেয়।

## ডিপ্লয় (একবারই, ৫ মিনিট — বিনামূল্যে)
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Create Worker**।
2. নাম দিন `potrodip-share` → **Deploy** → এরপর **Edit code**।
3. এডিটরের সব কোড মুছে `share-worker/worker.js`-এর পুরোটা পেস্ট করুন → **Deploy**।
4. ওয়ার্কারের ঠিকানাটা কপি করুন, যেমন `https://potrodip-share.আপনার-নাম.workers.dev`।
5. `assets/js/core/config.js`-এ বসান (শেষে `/` ছাড়া):
   ```js
   shareBase: 'https://potrodip-share.আপনার-নাম.workers.dev',
   ```
6. সাইট GitHub-এ পুশ করুন।

অতিরিক্ত কোনো Variable/Secret দিতে হবে না (Supabase-এর পাবলিক anon কী ও সাইটের ঠিকানা কোডেই আছে)। বদলাতে চাইলে Worker → Settings → Variables-এ `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SITE_ORIGIN` দিলে সেটাই চলবে।

## ব্যবহার
- লেখার পেজের **ফেসবুক / হোয়াটসঅ্যাপ / লিংক-কপি** বাটন এখন নিজে থেকেই `…workers.dev/a/<লেখার-id>` লিংক দেয়।
- লেখকের প্রোফাইলের শেয়ার-বাটন দেয় `…workers.dev/w/<slug>`।
- ব্রাউজারের অ্যাড্রেস-বার থেকে `article.html?id=…` কপি করলে আগের মতো লোগোই দেখাবে — শেয়ার করতে বাটন বা `/a/<id>` লিংক ব্যবহার করুন।

## পরীক্ষা
- ফেসবুক: https://developers.facebook.com/tools/debug/ → লিংক দিয়ে **Scrape Again**।
- এক্স/টুইটার ও লিংকডইনেরও নিজস্ব প্রিভিউ-যাচাই টুল আছে।
- আগে একবার ফেসবুকে শেয়ার হওয়া লিংকের প্রিভিউ ফেসবুক ক্যাশ করে রাখে; নতুন `/a/<id>` লিংকে এটা হয় না।

## নোট
- শুধু `status = published` লেখাই দেখায়; খসড়া কখনো নয়।
- কভার-ছবি না থাকলে লোগো দেখায়।
- ছবির ফাইল ছোট (ভালো হয় ৩০০ KB-এর নিচে, ১২০০×৬৩০ প্রায়) হলে হোয়াটসঅ্যাপে প্রিভিউ নির্ভরযোগ্যভাবে আসে।
- নিজের ডোমেইন কিনলে ওয়ার্কারটা সেই ডোমেইনে বসানো যায়, তখন লিংকে `workers.dev`-এর বদলে নিজের নাম থাকবে।
